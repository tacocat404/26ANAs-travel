  - **1단계 일정 조율**(`CalendarTab`): 기존 안 되는 날 표시·낙관적 업데이트·모두 되는 주말 추천 위에 **가는 날 확정**을 얹음. 추천 주말 칩을 탭하면 그 주말(토~일)로 원탭 확정, 날짜를 선택하면 "이 날로 확정"·"여기까지 기간 넓히기"로 직접 확정. 확정되면 상단에 "가는 날 확정: 2026.08.15(토)~16(일)" 배너 + "다시 조율"(해제), 확정 기간은 달력에 진하게 표시.

### [구현] UX/편의성 개편 라운드 (worktree-design-ux 브랜치, GAN 방식)
- **사용자 프롬프트(요약)**: git worktree로 브랜치를 분리하고, 이 세션은 디자인 색감·UI/UX·사용자 편의성·리팩토링 담당. GAN처럼 비판가/개선자 상호조언으로 필요한 일을 찾아 개편해 달라.
- **Claude의 변경사항** (비판가 라운드 1에서 8건 유죄 판정 후 전부 수정):
  - **모두 갈 수 있는 주말 추천**: 캘린더 아래 카드로, 보고 있는 달에서 토+일 모두 아무도 표시 안 한 주말을 칩으로 추천 (멤버 2명 이상일 때, 지난 주말 제외). 칩을 탭하면 그 날짜가 선택됨.
  - **캘린더 낙관적 업데이트**: 날짜 탭 시 서버 응답을 기다리지 않고 즉시 화면 반영 (공유 모드에서 렉 제거). 실패하면 원래대로 되돌림. 날짜 패널에 "내가 안 되는 날로 표시했어요, 다시 탭하면 취소" 안내 추가.
  - **탭 상태 유지(keep-alive)**: 여행 상세의 4개 탭을 한 번 열면 숨김 처리만 하고 유지. 지도 확대 상태·캘린더 선택이 탭을 오가도 사라지지 않음 (지도는 다시 보일 때 크기 재계산).
  - **확인 대화상자 통일**: 브라우저 기본 confirm/alert 전부 제거하고 앱 디자인과 같은 모달로 교체 (`src/confirm.jsx`). 삭제류는 빨간 "삭제" 버튼, Esc/바깥 탭으로 취소. 갤러리 업로드 실패는 alert 대신 인라인 오류 문구.
  - **캘린더 선택 표시 버그 수정**: "선택한 날" 테두리가 "내 안 되는 날" 테두리에 덮여 안 보이던 것을 링(이중 그림자) 방식으로 분리.

### [구현] 긴 공지가 대시보드 밖으로 넘치던 문제 수정
- **사용자 프롬프트(요약)**: (스크린샷) 글이 길면 오바된다 — 홈 대시보드 "최근 공지"의 긴 글이 카드 밖으로 밀려 화면이 옆으로 늘어남.
- **원인**: 대시보드는 데스크톱에서 `.dash-grid`가 2열인데, **그리드 칸의 기본값 `min-width: auto`** 때문에 칸이 내용의 min-content보다 좁아질 수 없었다. 공지 글에 `white-space: nowrap`이 걸려 있어 min-content = 글 전체 길이 → 칸이 그만큼 넓어지며 레이아웃이 화면 밖으로 밀렸다. (`.dash-notice-body`엔 `min-width:0`이 있었지만, 정작 그리드 칸인 `.dash-panel`에 없어 무의미했다.)
- **Claude의 변경사항** (styles.css만):
  - `.dash-panel`에 `min-width: 0` — 그리드 칸이 줄어들 수 있게(근본 원인).
  - `.dash-trip`/`.dash-notice`(버튼)에도 `min-width: 0`.
  - 공지 미리보기를 **한 줄 줄임표 → 두 줄 줄임표**로(`-webkit-line-clamp: 2`). 한 줄은 정보가 너무 적고, 전문은 눌러서 여행 공지 탭에서 본다. line-clamp를 못 쓰는 브라우저용으로 `max-height` 안전망도 함께.
  - `overflow-wrap: anywhere` 추가 — 띄어쓰기 없는 긴 글/링크도 넘치지 않게. 같은 이유로 여행 상세 `.notice-body`에도 적용.
  - 공지 줄이 여러 줄이 되니 아바타 정렬을 `flex-start`로(첫 줄과 눈높이).
- **검증**: 실제 DB의 141자 공지로 확인 — 데스크톱 1280: 가로 넘침 0(문서 1265px), 그리드 1036px 안에 정확히 맞고 공지는 2줄(41px)로 접힘. 모바일 375: 넘침 0(문서 375px), 동일하게 2줄. 공지를 누르면 여행 공지 탭에서 **141자 전문이 잘림 없이** 표시. 콘솔 0, 빌드 성공.

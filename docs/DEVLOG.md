# 개발 일지 (DEVLOG)

## 2026-07-24

### [구현] 지도 대개편 - 스타일 행정구역 지도 + 장소 핀 루트 (design-taste-frontend)
- **사용자 프롬프트(요약)**: "감도 여행 다트" 레퍼런스처럼 행정구역이 색깔별로 칠해진 지도로. 구역을 탭하면 확대되고, 그 안에서 맛집/갈 곳에 핀을 찍으면 선으로 이어지게. 전체적으로 웹 기준 큼지막한 UI로.
- **Claude의 변경사항**:
  - 통계청(KOSTAT) 시군구 경계 데이터(southkorea-maps, 경량 95KB) 도입 → 딥블루 바다 위에 시도별 파스텔 색 모자이크 지도 렌더링 (시군구 251개 + 시도 라벨 17개). 데이터는 지도 탭 진입 시에만 로드(코드 스플릿).
  - 구역 탭 → 확대(포커스) 모드: 거리 지도(OSM)가 나타나고 선택 구역 밖은 어둡게 마스킹. "후보지로 담기" 또는 핀을 찍으면 자동으로 후보지에 담김. 담긴 구역은 전체 지도에서 진하게 표시.
  - 포커스 모드에서 지도 탭 = 장소 핀(번호, 추가한 사람 색) → 찍은 순서대로 선(잉크+흰 점선)으로 연결. 장소 목록/삭제 UI 포함.
  - 데이터 모델: regions에 code 추가, places 테이블 신설(supabase/schema.sql 갱신, 데모 모드 동일 반영).
  - 웹 와이드 레이아웃: 900px 이상에서 앱 폭 1100px, 지도 64vh, 탭·캘린더·글자 크게, 여행 카드 2열.
- **다음 단계**: Supabase 연결 시 갱신된 schema.sql 사용(기존 프로젝트가 이미 있으면 regions.code / places만 추가). 이후 아이디어: 핀 순서 바꾸기, 구역별 색 커스텀.

### [구현] 디자인 전면 개편 v2 — "잉크 & 멤버 컬러" (taste-skill, GAN 방식)
- **사용자 프롬프트(요약)**: taste-skill을 사용해 디자인 전면 개편. 비판가/개선자 역할을 나눠 GAN처럼 반복.
- **Claude의 변경사항**:
  - 비판가 라운드 1에서 7건 유죄 판정: AI 기본 크림+산호 팔레트, 이모지가 UI 아이콘 역할, 다크 모드 없음, 모션 없음, 오늘 날짜 표시 없음, 포커스 상태 없음, 포인트색이 멤버 색과 충돌.
  - 개선: 모노크롬 잉크 베이스(zinc)로 전환 — 화면에서 색을 가진 건 오직 "사람(멤버 색)". 다크 모드 자동 지원(지도 타일 감광 포함), Phosphor 아이콘 도입(이모지는 여행 심볼 등 콘텐츠에만), 오늘 날짜 잉크 원 마커, 지도 핀 색 = 추가한 사람 색, 절제된 모션(등장/눌림, reduced-motion 존중), focus-visible 링, 반경 3단 체계(카드16/컨트롤12/칩 pill).
  - 비판가 라운드 2(기계식 감사): 잔존 이모지 0, em-dash 0, 버튼 대비 정상, 라이트/다크 토큰 플립 확인, 오늘 마커·핀 색 확인 후 잔여 결함(업로드 버튼 폭) 수정. 프로덕션 빌드 성공.
- **다음 단계**: Supabase 연결·배포는 기존 계획대로 (`docs/SETUP.md`).

### [기획] "언제갈까?" 여행 일정 캘린더 기획
- **사용자 프롬프트(요약)**: 친구들과 여행 일정을 짜는 캘린더 앱. 날짜 클릭으로 각자 "안 되는 날"을 색깔로 표시, 비밀번호 없이 이름만으로 로그인. 여행별로 분류하고 지도(후보지)·갤러리·공지 기능 추가. 시니어 개발자 관점으로 기획해 달라. 기획→디자인→구현 순서.
- **Claude의 변경사항**: `docs/PLAN.md` 작성 — 핵심 기능 6개(F1~F6), 설계 결정("안 되는 날"은 사람 기준 전역 저장, 저장소 2단 구조: 데모 모드↔Supabase 공유 모드), 화면 흐름, 디자인 방향(모바일 우선·크림+산호색), 로드맵.

### [구현] 앱 전체 구현 (데모 모드 완동)
- **Claude의 변경사항**:
  - React + Vite 프로젝트 생성. 화면: 이름 로그인 → 여행 목록 → 여행 상세(캘린더/지도/공지/갤러리 4탭).

- **다음 단계**: ① 운영자가 Supabase 프로젝트 생성 후 키 전달(`docs/SETUP.md` 1단계) → 공유 모드 전환. ② GitHub 저장소 + Vercel 배포(2단계). ③ 이후: 후보지 투표, 전원 가능일 자동 추천.

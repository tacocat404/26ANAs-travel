# 언제갈까? — 여행 일정 캘린더 기획서

> 2026-07-23 작성. 친구들과 여행 날짜·장소를 정하는 웹앱.

## 1. 한 줄 소개
친구들이 각자 **"안 되는 날"을 색깔로 표시**해서, 모두 갈 수 있는 여행 날짜를 한눈에 찾는 앱.

## 2. 사용자와 전제
- 사용자: 친한 친구 소그룹 (2~10명). 링크를 아는 사람만 사용.
- 보안보다 **편의 우선**: 비밀번호 없이 이름만으로 로그인. (친구끼리라 서로 사칭할 이유가 없다는 전제 — 알려진 트레이드오프)

## 3. 핵심 기능 (MVP)
| # | 기능 | 설명 |
|---|------|------|
| F1 | 이름 로그인 | 기존 이름 탭 또는 새 이름 입력. 사람마다 고유 색깔 자동 배정 |
| F2 | 여행 만들기 | 이름 + 이모지 + 후보 시기(월 범위). 여행별로 지도/공지/갤러리/캘린더 묶음 |
| F3 | 캘린더 | 날짜를 탭하면 **내가 안 되는 날** 표시/해제. 친구들 것은 색 점으로 표시. 날짜를 고르면 누가 안 되는지 이름 확인 |
| F4 | 지도 | 지도를 탭해서 후보지 핀 추가 (OpenStreetMap, 무료) |
| F5 | 공지 | 여행별 공지 작성, 📌 고정, 작성자만 삭제 |
| F6 | 갤러리 | 사진 업로드(자동 압축), 올린 사람만 삭제 |

## 4. 중요한 설계 결정 (시니어 개발자 관점)
1. **"안 되는 날"은 사람 기준(전역)으로 저장** — 7/5에 안 되는 사람은 어느 여행이든 안 되는 것. 한 번 표시하면 모든 여행 캘린더에 같이 보인다. 여행마다 따로 찍는 수고 방지.
2. **저장소 2단 구조**
   - 지금(데모 모드): 브라우저에 저장 → 설치·계정 없이 바로 동작. 단, **내 기기에만 보임**.
   - 공유 모드: 무료 서버(Supabase)에 저장 → 친구들 모두 같은 데이터를 봄. `src/config.js`에 주소 2줄만 넣으면 자동 전환. (계정 만들기는 운영자가 직접 — `docs/SETUP.md` 참고)
3. **사진은 자동 압축**(최대 1000px, JPEG) — 무료 용량으로 충분히 버티게.
4. 지도는 **Leaflet + OpenStreetMap** — API 키·요금 없음.

## 5. 화면 흐름
```
이름 로그인 → 여행 목록(+ 여행 추가) → 여행 상세
                                   ├ 🗓️ 캘린더 (기본 탭)
                                   ├ 🗺️ 지도
                                   ├ 📢 공지
                                   └ 📷 갤러리
```

## 6. 디자인 방향
- **모바일 우선** (폰으로 쓸 확률 99%). 데스크톱에선 가운데 480px 카드형.
- 감성: 따뜻하고 귀여운 여행 무드. 크림색 배경 + 산호색 포인트 + 사람별 비비드 컬러.
- 색: 배경 `#FAF6EF`, 글자 `#2B2724`, 포인트 `#FF6B57`, 사람 색 10종 팔레트.
- 글꼴: Pretendard. 모서리 둥근 카드(16px), 부드러운 그림자.
- 캘린더: 내가 안 되는 날 = 내 색으로 칠해짐 / 친구 = 색 점 / 일요일 빨강·토요일 파랑.

## 7. 기술 스택
- React + Vite (화면), Leaflet(지도), Supabase(공유 저장소 + 동영상 보관함), GitHub Pages(배포)

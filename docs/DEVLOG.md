- **Claude의 변경사항**:

  - 포커스 모드: 지도 위 검색창(OpenStreetMap Nominatim, 무료·키 없음) → 결과 탭 → 지도 이동 + 이름이 미리 채워진 핀 확인 폼 → 핀 찍기. 구역 안 결과 우선 정렬, 빈 결과/오류 안내문 포함.

  - 한계 메모: 맛집 데이터는 OSM 기준이라 네이버보다 빈약할 수 있음. 부족하면 카카오 로컬 API(무료 키 필요, 운영자 발급)로 교체 가능하게 검색 함수를 한 곳(runSearch)에 모아둠.

### [구현] 지도 대개편 - 스타일 행정구역 지도 + 장소 핀 루트 (design-taste-frontend)
- **사용자 프롬프트(요약)**: "감도 여행 다트" 레퍼런스처럼 행정구역이 색깔별로 칠해진 지도로. 구역을 탭하면 확대되고, 그 안에서 맛집/갈 곳에 핀을 찍으면 선으로 이어지게. 전체적으로 웹 기준 큼지막한 UI로.
- **Claude의 변경사항**:
  - 통계청(KOSTAT) 시군구 경계 데이터(southkorea-maps, 경량 95KB) 도입 → 딥블루 바다 위에 시도별 파스텔 색 모자이크 지도 렌더링 (시군구 251개 + 시도 라벨 17개). 데이터는 지도 탭 진입 시에만 로드(코드 스플릿).
  - 구역 탭 → 확대(포커스) 모드: 거리 지도(OSM)가 나타나고 선택 구역 밖은 어둡게 마스킹. "후보지로 담기" 또는 핀을 찍으면 자동으로 후보지에 담김. 담긴 구역은 전체 지도에서 진하게 표시.
  - 포커스 모드에서 지도 탭 = 장소 핀(번호, 추가한 사람 색) → 찍은 순서대로 선(잉크+흰 점선)으로 연결. 장소 목록/삭제 UI 포함.
  - 데이터 모델: regions에 code 추가, places 테이블 신설(supabase/schema.sql 갱신, 데모 모드 동일 반영).
  - 웹 와이드 레이아웃: 900px 이상에서 앱 폭 1100px, 지도 64vh, 탭·캘린더·글자 크게, 여행 카드 2열.
- **다음 단계**: Supabase 연결 시 갱신된 schema.sql 사용(기존 프로젝트가 이미 있으면 regions.code / places만 추가). 이후 아이디어: 핀 순서 바꾸기, 구역별 색 커스텀.

## 왜 만들었나

친구들끼리 여행 얘기가 나오면 늘 똑같은 흐름이 반복됩니다.
단톡방에서 "언제 시간 돼?"를 몇 번이나 묻고, 각자 안 되는 날이 흩어져서
결국 아무도 전체 그림을 못 봅니다. 날짜를 겨우 정해도 이번엔
가고 싶은 곳 링크가 대화 속으로 사라지고, 다녀온 사진은 앨범에 묻힙니다.

**언제갈까?** 는 그 과정을 한 곳에 모읍니다.
날짜를 맞추고, 갈 곳을 정하고, 다녀온 기록을 남기는 것까지 여행 한 번의 처음과 끝을요.

## 주요 기능

### 날짜 맞추기

각자 자기가 **안 되는 날**만 캘린더에 표시합니다. 아무도 표시하지 않은 날이
자연스럽게 "다 같이 되는 날"로 드러나고, 홈 화면에서 바로 확인할 수 있습니다.
마음에 드는 날짜를 고르면 **가는 날로 확정**되고 여행이 다음 단계로 넘어갑니다.

- 사람마다 고유한 파스텔 색이 배정되어, 누가 안 되는 날인지 색으로 구분됩니다
- "안 되는 날" 표시는 사람 기준으로 저장되어 모든 여행에 함께 반영됩니다
- 앞으로 60일 안에서 전원 가능한 날을 자동으로 찾아 홈에 띄웁니다

### 갈 곳 정하기

전국 행정구역이 색으로 칠해진 지도에서 가고 싶은 지역을 고릅니다.
지역을 누르면 확대되고, 그 안에서 맛집·명소를 **이름으로 검색**해 핀을 꽂습니다.
핀은 꽂은 순서대로 선으로 이어져 자연스럽게 동선이 그려집니다.

- 통계청(KOSTAT) 시군구 경계 데이터로 만든 스타일 지도 (시군구 251개)
- 장소 검색은 카카오 로컬 검색을 쓰고, 키가 없으면 OpenStreetMap으로 자동 대체
- 핀 색은 그 장소를 추가한 사람의 색

### 기록으로 남기기

여행 날짜가 지나면 자동으로 **끝난 여행**으로 넘어가고, 함께 올린 사진이
한 권처럼 정리됩니다. 공지와 회비 이야기도 여행별로 모입니다.

- 사진은 업로드할 때 자동 압축 (최대 1000px, JPEG)
- 홈 갤러리에서 여행별로 묶어 잡지처럼 배치
- 공지는 고정(📌)해서 위로 올릴 수 있음

### 우리끼리만

링크를 아는 아무나 들어올 수 없도록 **입장 코드**를 통과해야 참여할 수 있습니다.
관리자는 별도 PIN으로 들어가 입장 코드 변경, 멤버·여행 정리를 할 수 있습니다.

> 입장 코드와 관리자 PIN은 낯선 사람의 진입을 막는 가벼운 잠금장치입니다.
> 친구들끼리 쓰기에는 충분하지만, 기술적으로 우회가 가능한 수준이라는 점은 알고 쓰세요.

## 디자인

일기 앱에서 출발한 **부드러운 파스텔 기록장** 스타일입니다.

- 웜 화이트 배경 위에 흰 카드, 큰 둥근 모서리(22px), 옅은 그림자
- 포인트 색은 부드러운 복숭아 하나. 화면에서 진짜 색을 갖는 건 **사람(멤버 색)** 뿐
- 사람은 파스텔 블롭으로 표현되고, 날짜·라벨에는 손글씨(Gaegu)를 씁니다
- 라이트 / 다크 모드 자동 전환, 모바일 우선 (넓은 화면도 대응)

## 기술 스택

| 영역 | 사용 |
|---|---|
| 프론트엔드 | React 18, Vite 5 |
| 데이터 | Supabase (PostgreSQL) |
| 지도 | Leaflet, OpenStreetMap, 통계청 행정구역 경계 |
| 장소 검색 | 카카오 로컬 (없으면 Nominatim으로 대체) |
| 아이콘 / 폰트 | Phosphor Icons, Pretendard, Gaegu |
| 배포 | GitHub Pages (GitHub Actions 자동 배포) |

데이터 저장소는 **두 가지 모드**로 동작합니다.
`src/config.js`에 Supabase 키가 있으면 **공유 모드**(친구들이 같은 데이터를 봄),
비어 있으면 **데모 모드**(브라우저에만 저장)로 자동 전환됩니다.
두 모드는 같은 인터페이스를 쓰기 때문에 코드에서 신경 쓸 일이 없습니다.

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

http://localhost:5173 에서 열립니다. Supabase 키가 없으면 데모 모드로 바로 실행됩니다.

```bash
npm run build     # 프로덕션 빌드
npm run preview   # 빌드 결과 미리보기
```

## 설정하기

Supabase 연동, 카카오 장소 검색, 입장 코드 저장 등 모든 설정 방법은
[**docs/SETUP.md**](docs/SETUP.md) 에 단계별로 정리되어 있습니다.

- 아무 설정 없이도 데모 모드로 바로 실행됩니다
- Supabase를 연결하면 친구들과 데이터가 공유됩니다
- 카카오 키를 넣으면 장소 검색이 더 촘촘해집니다
